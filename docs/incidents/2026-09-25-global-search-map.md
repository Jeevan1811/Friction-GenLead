# Incident: global prospect search and map unavailable

- **Surface / symptom:** Production `/search` still showed a disabled research action and QLD-only inputs. `/locations` showed “Map view unavailable”; the browser reported a malformed Cesium chunk followed by `ChunkLoadError`.
- **Impact:** MSV could not discover new companies through the dashboard or view saved locations on the map. The existing workbook/Google Sheets data was not deleted or rewritten by this incident.
- **Evidence:** Read-only production browser inspection recorded in `docs/WORKLOG.md` on 2026-09-25. Bounded searches to both configured public Overpass endpoints from the VPS timed out or returned HTTP 504. The previously deployed UI was not connected to a live research provider. The old Cesium build failed on the target runtime.
- **Root cause:** Confirmed. The deployed search path had no reliable global discovery adapter; its historical fail-closed behavior correctly avoided fake results but left the feature unavailable. The selected public Overpass endpoints were not reliable for this app. The 3D Cesium bundle failed in production; the locations page therefore could not load its map.
- **Recovery:** Replace primary search with bounded queries against the latest Overture Maps Places release, geocode user-entered locations, keep QLD ABR as a supplement, preserve source/release/confidence/license metadata, deduplicate against canonical and rejected Sheets rows, crawl only a listed public website through the existing SSRF/robots-checked crawler, and save candidate/location/contact rows to Sheets. Replace the Cesium map with Leaflet. Do not include the separately implemented trusted-device auth change in this release.
- **Prevention:** Backend tests cover source mapping, release validation, bounded sector queries, deduplication, Sheet persistence, contact crawling, and failure states. Release checks require production API health, a real read-only Overture query on the VPS, named GenLead process checks, and read-only browser verification of `/search` and `/locations`; never run PM2 as root to inspect or restart another app.
- **Closure state:** Source implementation and local tests are complete; production deployment and post-deploy browser/API verification are pending. Do not mark closed until those live checks pass. A real authenticated search that writes candidates is a separate production-data action and must not be simulated with fake companies.
