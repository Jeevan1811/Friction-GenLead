# Incident: Original data register difficult to scan and navigate

- **Surface / symptom:** The `/source-data` screen presented repeated per-record card content and a wide raw-field panel. Users had to expand rows to inspect original workbook facts, and source rows did not link directly to their company. The top navigation also fell back to the generic product title on this route.
- **Impact:** MSV's workbook evidence remained stored in Google Sheets, but reviewing and moving from a source row to its company required extra effort. The old UI filtered blank raw cells from the disclosure and used a 560px minimum panel width; no source-cell deletion or mutation was found in this UI path.
- **Evidence:** User-provided page screenshot; source review of `apps/web/src/app/(dashboard)/source-data/page.tsx`, `apps/web/src/components/layout/header.tsx`, and `apps/web/src/lib/types.ts`; local synthetic-data browser preview on 2026-09-28. The source record carries the original serialized snapshot in `rawDataJson`.
- **Root cause:** Confirmed presentation/data-view contract defects: summary metadata was repeated, `rawCells` discarded empty-valued cells, the disclosure imposed a fixed minimum width, no company link was rendered, and `/source-data` was absent from `pageTitles`.
- **Recovery:** Replace the repeated cards with compact provenance-first rows; link only when `companyId` is present; disclose every stored raw field including blanks; show malformed snapshot text unchanged; make the field grid responsive; add the missing title and singular count grammar. The Sheet data and backend were not changed.
- **Prevention:** `apps/web/tests/source-data-record.test.mjs` covers encoded company navigation, preservation of all literal raw values including empty and special-character values, unmatched rows, and malformed snapshots. Local browser QA covered filtering, company drawer navigation, keyboard/native disclosure behavior, no horizontal overflow at 320/375/390/768/1024/1280/1440px, and console errors.
- **Production closure:** PR #22 and line-ending follow-up PR #23 were merged; commit `e5900ed7a1dea54604e26e9bf7d9c988cb6bae6a` was deployed to the VPS. Authenticated read-only QA loaded 50 Original data rows, 50 full-field disclosures, and 50 company links; a link opened the matching company selection. Search showed the 10–100 target slider (default 30) and Valve-focused default. No new production search or Sheet write was submitted.
