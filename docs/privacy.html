Privacy Policy

Last updated: September 2026

Friction GenLead is a personal-use internal tool for Queensland business prospecting. It is not a public product, has no public sign-up, and is used by a single authorized developer/operator.

What Google data this app accesses

This app requests access to the Google Sheets API (https://www.googleapis.com/auth/spreadsheets) for one purpose only: to read and write rows in a single Google Sheet owned by the app's operator, used as the app's data store for business-prospect records (company names, ABNs, contact details, verification status).

How this data is used

Data read from or written to the sheet stays within the app's own backend and the operator's own Google account. It is never shared with, sold to, or accessed by any third party, and is never used for advertising or any purpose beyond running this tool.

Data retention and deletion

Data persists only in the operator's own Google Sheet, under their full control. Access can be revoked at any time via Google Account permissions, which immediately stops this app from accessing the sheet.

Contact

Questions about this policy can be raised via the project's GitHub repository.
