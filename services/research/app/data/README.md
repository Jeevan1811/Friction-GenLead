`au_postcodes.json` — postcode → [latitude, longitude, first place name], the
average of every GeoNames place sharing that postcode (approximate centre).

Source: GeoNames postal code dump `AU.zip` (https://download.geonames.org/export/zip/),
licensed CC BY 4.0 — https://creativecommons.org/licenses/by/4.0/. Attribution: GeoNames (geonames.org).
Used to place locations on the map when a site has no exact coordinates, and
to centre automated research on a postcode.
